Raccoon Raiders is a grid-based strategy game implemented in Python. The player moves around a game
board and attempts to prevent raccoons from reaching garbage cans by pushing recycling bins, closing
garbage cans, and trapping raccoons. The game includes regular and smart raccoons with different
movement behaviors, interactive objects, turn-based gameplay, scoring, and a graphical interface
built with Pygame.

This project covers core computer science concepts including object-oriented programming, inheritance,
polymorphism, composition, and game-state management. It also involves algorithm design for movement,
collision handling, path selection, trapping detection, and scoring, along with unit testing and
debugging to verify interactions between game components.
